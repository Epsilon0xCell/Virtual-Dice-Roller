Virtual-Dice-Roller

dice.py is one Python file. Python 3, standard library only, nothing to install. It rolls standard dice notation from the command line or in an interactive session that keeps history and statistics.

Open the repo The interactive session

First settle: the notation

ExpressionMeaning
3d6roll 3 six-sided dice
d20roll 1 twenty-sided die
2d20+5roll 2d20 and add 5
1d8-1roll 1d8 and subtract 1
4roll 4 six-sided dice

Limits, written plainly: 1 to 1000 dice, 2 to 10000 sides, and a modifier between minus 1000000 and plus 1000000. An expression outside those limits or in any other format is rejected with an error message.

Field note: a modifier may pull a total below zero. 1d2-5 can print a negative total, and nothing clamps it, because some games use negative results on purpose.

Second settle: batch runs

python3 dice.py 3d6            # single roll
python3 dice.py 2d20+5 1d8     # several rolls at once
python3 dice.py --seed 42 4d6  # reproducible rolls
python3 dice.py                # interactive mode

Several expressions may follow at once, and rolls are printed in order. The verified example with a fixed seed, printed in full:

$ python3 dice.py --seed 42 4d6 2d20+5 1d8-1
4d6: [6, 1, 1, 6] = 14
2d20+5: [9, 8] +5 = 22
1d8-1: [4] -1 = 3

Field note: if one expression is invalid, batch mode prints Error: ... to standard error, stops at that point, and exits with status 2, while rolls already printed stay printed.

Last settle: the interactive session

Run with no arguments and type any dice expression to roll it. history lists every roll of the session, with modifiers shown. stats gives count, minimum, maximum, average and total across the session. quit, exit, or q leaves, printing the final stats. An invalid expression prints an error and the session continues. Typing history or stats before any roll prints No rolls yet. Closing input (EOF) or pressing Ctrl-C ends the session and prints the final stats. Exit status is 0.

The test suite is test_dice.py, 17 tests, run with python3 -m unittest. The whole program is dice.py; the licence is MIT.
