Virtual-Dice-Roller

dice.py is one Python file. Python 3, standard library only, nothing to install. It rolls standard dice notation from the command line or in an interactive session that keeps history and statistics.

Register page one: the notation

EntryMeaning
3d6rolls three six sided dice
d20rolls one twenty sided die
2d20+5adds five after the roll
1d8-1subtracts one
4a bare number rolls that many six sided dice

Limits, written plainly: 1 to 1000 dice, 2 to 10000 sides, a modifier between minus 1000000 and plus 1000000.

Field note: a modifier may pull a total below zero. 1d2-5 can print a negative total, and nothing clamps it, because some games use negative results on purpose.

Register page two: batch runs

python3 dice.py 3d6
python3 dice.py 2d20+5 1d8
python3 dice.py --seed 42 4d6

Several expressions may follow at once. --seed 42 repeats a roll exactly, and seed 0 is included as a real seed. The verified example, printed in full:

$ python3 dice.py --seed 42 4d6 2d20+5 1d8-1
4d6: [6, 1, 1, 6] = 14
2d20+5: [9, 8] +5 = 22
1d8-1: [4] -1 = 3

Field note: if one expression is invalid, batch mode prints an error to standard error, stops at that point, and exits with status 2, while rolls already printed stay printed.

Register page three: the interactive session

Run with no arguments and type any expression. history lists every roll of the session with its modifier shown. stats gives count, minimum, maximum, average, and total. quit, exit, or q leaves. An invalid entry prints an error and the session continues. Typing history or stats before any roll prints No rolls yet. Closing input or pressing Ctrl-C ends the session, prints the final statistics, and exits with status 0.

The test suite is test_dice.py, 17 tests, run with python3 -m unittest.
